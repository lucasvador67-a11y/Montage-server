Fichier / URL YouTube / URL directe → clips de 10s à 5min

Comment ça marche : importe une vidéo depuis ton appareil, par URL directe (mp4/webm) ou via une URL YouTube / Vimeo / TikTok grâce au serveur backend. L'app analyse, détecte les meilleurs moments, et génère 10 à 30 clips avec zoom, cuts et montage. Durées de clips disponibles de 10 secondes à 5 minutes.

⚠️ Serveur requis pour YouTube / Vimeo / TikTok
Ces plateformes sont protégées par DRM. Pour les télécharger, il faut un serveur backend (comme fait Opus Clip). Sans serveur configuré, utilise :
1. yt-dlp en ligne de commande pour télécharger la vidéo, puis l'onglet 📁 Fichier local
2. Une URL directe vers un fichier .mp4 / .webm hébergé publiquement

Le code du serveur backend est fourni dans la documentation de Montage Studio v3.
